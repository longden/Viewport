Notarized macOS release. Requires macOS 26 or later. The download contains the signed, notarized Viewport app.

This release replaces 0.3.0, whose download could not be opened. macOS reported that Apple could not verify the app because of a packaging problem in the ZIP. The app itself was unchanged; 0.3.1 ships the same features in a correctly packaged archive.

## In-app updates

Viewport can now update itself. Open **Updates…** from the Viewport menu or the Settings menu in the toolbar to check for new versions, read release notes, and install. Automatic checking is optional and off until you turn it on. Installing always requires an explicit action, and the restart waits until any recording or Build & Play run has finished.

This is the first release with the updater, so existing users need to download this version manually once. Later releases can be installed from inside Viewport.

## Quitting

- Quitting while recording now asks whether to save or discard the recording.
- Quitting is blocked while Build & Play is running or a recording is being saved, with a message explaining why.
